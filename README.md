Assignment Overview
In this assignment, you’ll evaluate the distributions of your continuous variables in your dataset and apply basic probability concepts to analyze real-world scenarios. You’ll work entirely in Excel to perform these calculations.

This assignment will reinforce your ability to:

Assess whether variables follow normal or skewed distributions

Make assumptions explicit

Use probability concepts to answer business-relevant questions

Requirements
1. Distribution Assessment 
For all continuous variables from your dataset.

Create a new tab titled “Distribution Analysis.”

Include:

A histogram of each variable

A normal curve overlay (optional but encouraged)

Summary statistics: Mean, Median, Std Dev, Skewness, Kurtosis

A short written interpretation (1-2 sentences) for each variable:

Is it approximately normal? Skewed? Bimodal?

Do the assumptions for normal probability appear to be valid?

Create a tab titled “Probability Scenarios.”

Choose one variable to use for probability-based scenarios (preferably a continuous one like income, price, or rating).

Create and solve 3 different probability problems based on the data distribution. Examples:

What is the probability a customer spends more than $150?

What’s the chance a review rating falls below 3 stars?

What proportion of apartments cost between $100–$150?

Use:

The normal distribution (z-scores) only if assumptions appear to be justified

The empirical distribution (percentiles) if the data is non-normal

For each problem, include:

The problem statement

The method used (normal vs. empirical)

A clear final probability answer

A brief explanation (1–2 sentences)
